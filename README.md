# ILAW: Food Webs and Ecosystem Changes

A standalone interactive HTML lesson plan for Year 7 Biology, based on the uploaded presentation.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then Save.
6. Open the published Pages URL after deployment completes.

## Features
- Responsive lesson overview and teacher lesson sequence
- Interactive learner tasks (biotic/abiotic sorting, food-chain sequence, ecosystem prediction)
- Food-web and coral-reef examples
- Auto-marked five-question quiz
- Printable worksheet and lesson (`Print`)
- Reflection checklist and teacher assessment notes

## Curriculum note
The uploaded presentation identifies Year 7 Biology and Australian Curriculum code AC9S7U02. Update the curriculum link if adapting this resource to a different local curriculum or school template.
